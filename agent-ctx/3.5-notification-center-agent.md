# Task 3.5 — Notification Center Agent

## Task: Implement Notification Center
Add a notification bell icon to the top bar that shows deadline warnings and project status alerts.

## Work Completed

### Files Created
1. **`src/stores/notification-store.ts`** — Zustand store managing notification state
   - `Notification` type: id, type (overdue/deadline_warning/status_change/payment_update), title, message, projectId, projectName, timestamp, read
   - `addNotification()`: Stable ID generation (projectId + type), deduplication
   - `markAsRead(id)`, `markAllAsRead()`, `clearAll()`
   - `generateFromProjects(projects)`: Scans for overdue deadlines, deadlines ≤3 days, UNPAID/PARTIAL payments. Skips COMPLETED/CANCELLED. Preserves read state. Sorts unread-first.

2. **`src/components/notifications/NotificationCenter.tsx`** — Notification panel component
   - Bell icon (w-4 h-4) with 8px red dot badge
   - shadcn/ui Popover with ScrollArea (max-h-96), max 10 items
   - Type-based icons: AlertTriangle (red/overdue), Clock (amber/deadline_warning), DollarSign (emerald/payment)
   - Color-coded left borders, unread blue dot indicator
   - Header with count badge, mark all read, clear all
   - Empty state, click-to-navigate, auto-refresh via useProjects()

### Files Modified

4. **`src/components/layout/AppShell.tsx`** — Added `onSelectProject` prop, passes to BreadcrumbNav
