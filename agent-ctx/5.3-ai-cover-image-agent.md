## Key Implementation Details
- Cover image stored as base64 string in database `coverImage` field
- AI generation uses `z-ai-web-dev-sdk` with auto-generated prompt from project data (category, name, tech stack)
- Size: 1344x768 (landscape) for optimal banner display
- Project list API excludes coverImage to avoid large payloads
- Single project API includes coverImage via Prisma spread
- UI: gradient placeholder when no cover image, base64 img tag when cover exists
- Popover with optional custom prompt input, Enter key to generate
- Toast notifications for success/error
- React Query cache invalidation after generation
