# Task 5.2 - Smart Insights Agent

## Summary
Implemented the Smart Project Insights widget for the Nexty Labs Project Tracker dashboard.

## Files Created
- `src/components/ai/SmartInsights.tsx` — Smart Insights widget with AI-powered project portfolio analysis

## Files Modified
- `src/components/views/DashboardView.tsx` — Added SmartInsights component import and placement between Charts row and Health Score section

## Key Implementation Details

### SmartInsights Component
- "use client" component that fetches AI insights on mount via POST /api/ai/insights
- Props: `{ onNavigate?: (view: string) => void }`
- Loading state: animated skeleton with pulse effect
- Insights renderer (`renderInsights`):
  - Emoji headers (📊⚠️💡📈) → bold, text-sm font-semibold
  - Bold text (** **) → text-text-main font-medium
  - Bullet points (-, •) → indented with pl-3
  - Empty lines → h-1 spacer
  - Regular text → text-xs text-text-muted
- Controls: Refresh (with spin animation), Minimize/Expand toggle
- Error state: AlertTriangle + "Gagal memuat insights" + retry button
- Cache: insights stored in state, only re-fetched on mount or manual refresh
- Content area: max-h-96 overflow-y-auto

### DashboardView Integration
- SmartInsights placed between Charts row and Health Score
- Wrapped in motion.div with itemVariants
- Passes onNavigate prop from DashboardView
